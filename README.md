# Super-Store-Sales-Dashboard-Power-BI
Power BI Super Store Sales Dashboard | Sales Analysis &amp; 15-Day Forecasting

📊 Project Overview

This project is an interactive Super Store Sales Dashboard developed in Microsoft Power BI Desktop to analyze sales, profit, quantity, customer segments, payment modes, shipping modes, categories, sub-categories, regions, and monthly performance.

The project also includes a 15-day Sales Forecasting report page.

🎯 Project Objectives

-Analyze overall sales and profit performance.
-Compare sales across categories and sub-categories.
-Understand regional sales and profit performance.
-Analyze customer segments and payment modes.
-Compare monthly sales and profit year-over-year.
-Analyze sales by shipping mode.
-Provide a 15-day sales forecasting view for future planning.

🗂️ Dataset

Dataset: SuperStore_Sales_Dataset.csv

-Records: 5,901
-Date range: 01 Jan 2019 – 31 Dec 2020
-Columns: 23
-Main business fields include Order Date, Ship Date, Ship Mode,
Customer, Segment, City, State, Region, Category, Sub-Category, Sales, Quantity, Profit, Returns and Payment Mode.

🛠️ Tools Used

-Microsoft Power BI Desktop
-Power Query / Power BI data preparation
-DAX / Power BI measures and calculations
-Interactive dashboard visuals
-Power BI forecasting visual

📌 Dashboard Pages

1) Super Store Sales Dashboard
The main dashboard contains:

-KPI cards for Sales, Profit, Quantity and Average value.
-Sales by Category
-Sales by Sub-Category
-Sales by Ship Mode
-Sales by Segment
-Sales by Payment Mode
-Monthly Sales YoY
-Monthly Profit YoY
-Sales and Profit by State
-Region slicers: Central, East, South and West

2) Sales Forecasting – 15 Days
The forecasting page contains:

-Historical sales trend by Order Date
-A 15-day sales forecasting view
-Forecast visualization extending into January 2021
-Detailed sales trend for the historical period
